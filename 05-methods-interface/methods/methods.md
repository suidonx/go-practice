## メソッドとは

- 定義
    - 特別なレシーバ引数を持つ関数
- レシーバは型のコピー
- 複数のメソッドを定義可能
- ドット記法
- Goにはクラスがない
- レシーバ
    - 呼び出しの時の左のuser, v
    - それぞれFullNameのレシーバ
```
user.FullName()
v.Abs()
```

## メソッドと関数の等価性

- 同じ処理で構文違う
- なぜメソッドを使う？関数と比べて
    - 読みやすさ
    - 名前空間

## 本質

- シンタックスシュガー
    - コンパイラが自動的に変換してくれる
    - 見た目が重要
- 型に関する処理
    - メソッド
- 汎用的な処理
    - 関数
- 任意の型（構造体以外）にもメソッドを定義可能
    - 同じパッケージで定義された型
    - レシーバの型はポインタまたは値

- 値レシーバはコピーを受け取る
- コピーに対して変更しているだけなので値は変わらない
- ポインタレシーバを引数にとる時、元の値も変わる。
    - いつ使うのか
        - 値を変更したい
        - 大きな構造体のコピーを避けるため。
    - 関数との違い
        - 実行時に、&vを渡す必要がある。関数の型を厳密にする必要がある

## ポインタレシーバと自動変換

- v.Scale(10)を(&v).Scale(10)と自動変換してくれて、簡潔に書ける。
- 実務ではほとんどポインタレシーバ
