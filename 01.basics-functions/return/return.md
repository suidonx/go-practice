## 複数の戻り値

- 複数の値を同時に返せる
- 括弧で囲んで型を並べる
- カンマ区切りで値を返す

## 便利なのか

- エラー処理
    - 結果とエラーを同時に返す
- 構造体が不要
    - jsだとobjectで返しがち

## 名前付き戻り値 naked return

- 短い関数でのみ使うべき
    - 何を返しているわかりにくいため
- ドキュメント目的

```
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return
}
```

- (x, y int)と戻り値の型注釈があって return だけ書いてあるのが基本のnaked return
