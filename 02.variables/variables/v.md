## 変数とは

- var を使う
- 初期値を入れないとゼロ値になる
    - stringは""
    - intは0
```
var age int
var b int
var (
    a int
    b int
    c int
)

```

## 初期化子付き変数宣言

```
var age int = 25
```

- ゼロ値を経由しないで、目的の値を代入

```
var age = 25 // intと型推論
var pi = 3.14 // float64と型推論
```

- コードが短くなる
- 型推論があっても、Goは静的型付け言語、型変更できない
    - 一度宣言された変数の型は変更できない
    - 型変換はできる

## 使い分け

## 短い変数宣言

```
age := 25
name := "taro"
isStudent := true
```

- 関数の中でしか使えない
- 関数の外のパッケージレベルでは使えない　

## := の注意点

- 再代入は=で
- 新しいのを含む時は:= OK
```
x := 20
x, y := 10, 20
```
