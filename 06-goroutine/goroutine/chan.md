## チャネル

```
c := make(chan int)
```

- 双方向 c
- 受信 <-c
- 送信 c<-

## バッファ付きチャネル

```
c := make(chan int, 2)  // 2個まで置ける
```

- 第2引数がバッファのサイズ（置き場の数）
- 空きがあるあいだは、受信がいなくても送信できる（ブロックしない）
- 満杯だと送信が待つ。空だと受信が待つ
- `make(chan int)` はバッファなし（サイズ0）。送受信が揃うまで両方待つ

```
c := make(chan int, 2)
c <- 1  // OK。置き場に入る
c <- 2  // OK。満杯
c <- 3  // 誰かが <-c するまでブロック
```

- デッドロックに注意
