## 定数

- 変更できない値
- const キーワード
- マジックナンバー
- 定数は := 宣言できない
- 再代入不可

## 数値定数の重要性

- 型は省略

## 定数が使える場所

- コンパイル時に値がわかるもの

## 命名規則

- キャメルケース
- SCREAMING_CASEは他の言語の慣習
- 頭が大文字でエクスポート
- 頭が小文字で非公開

## 型なし定数

```
const Pi = 3.14
```

- 使われる場所の型に自動的に合わせる
- 定数の高精度
    - 変数の型の制限を受けない

## ベストプラクティス

- 型なし定数を使う
    - 柔軟性が高い
- 型を明示する（特定の用途）
- 高精度が必要な時は定数
